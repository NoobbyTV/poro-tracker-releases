# Poro Tracker

A desktop companion for Riftbound on [Rift Atlas](https://play.riftatlas.com): play in the app and it tracks your games live (score, what's left in your deck, draw odds), keeps your match history and stats, builds an Insights report for each deck, saves replays, and can show your game on Discord.

This repository only holds the downloads. Get the newest version from **[Releases](../../releases/latest)**.

## Install

- **Windows:** download `Poro-Tracker-Setup-<version>.exe` and run it. The installer isn't code-signed, so Windows may say "Windows protected your PC": click **More info → Run anyway**.
- **Linux:** download `Poro-Tracker-<version>.AppImage`, make it executable (`chmod +x`) and run it. The `.tar.gz` works too: extract it and run `./poro-tracker`.

## Updates

Poro Tracker checks for a new version when it starts and every few hours, downloads it in the background, and installs it when you restart (Settings → Updates). The Windows installer and the AppImage update themselves; the `.tar.gz` tells you when a new version is out.

## Your data

Everything stays on your computer. Settings → Your data shows where your stats and replays are kept, lets you move them, and can export a backup file.
